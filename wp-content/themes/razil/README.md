# Тема Razil для WordPress

Block theme для сайта ритуального агентства «Земля и Люди» (ra-zil.ru).

## О теме

- **Название**: Razil
- **Тип**: Block Theme (на основе theme.json)
- **Требования**: WordPress 6.4+, PHP 8.0+
- **Статус**: Готово к использованию

## Структура

```
razil/
├── style.css                    ← Информация о теме
├── theme.json                   ← Палитра, типографика, макет
├── functions.php                ← Подключение стилей и шрифтов
├── assets/
│   ├── fonts/                   ← Локальные шрифты (.woff2)
│   ├── css/
│   │   ├── fonts.css           ← @font-face для шрифтов
│   │   ├── main.css            ← Основные стили + темная тема
│   │   └── editor-styles.css   ← Стили для редактора блоков
│   └── js/
│       └── (пусто - jQuery не используется)
├── templates/
│   ├── index.html              ← Архив постов
│   ├── front-page.html         ← Главная страница
│   ├── single-services.html    ← Отдельная услуга
│   ├── archive-services.html   ← Архив услуг
│   ├── single-products.html    ← Товар из каталога
│   ├── taxonomy-product_category.html ← Раздел каталога
│   ├── single.html             ← Обычный пост
│   ├── page.html               ← Страница
│   ├── search.html             ← Результаты поиска
│   └── 404.html                ← Страница ошибки
└── parts/
    ├── header.html             ← Шапка сайта
    └── footer.html             ← Подвал сайта
```

## Установка и активация

### 1. Тема уже установлена в `wp-content/themes/razil/`

### 2. Активируйте тему в WordPress

Откройте админ-панель:
1. Перейдите **Внешний вид → Темы**
2. Найдите **Razil**
3. Нажмите **Активировать**

### 3. Добавьте локальные шрифты

Тема требует двух шрифтов в формате `.woff2`:
- **PT Serif** (для заголовков) - начертания: 400, 700
- **Golos Text** (для текста) - начертания: 400, 600

**Вариант А: Автоматическая загрузка (PowerShell)**

```powershell
cd wp-content/themes/razil
.\download-fonts.ps1
```

**Вариант Б: Ручная загрузка**

1. Перейдите на https://fonts.google.com
2. Найдите **PT Serif** → скачайте `.woff2` начертания 400 и 700
3. Найдите **Golos Text** → скачайте `.woff2` начертания 400 и 600
4. Поместите файлы в папку: `wp-content/themes/razil/assets/fonts/`
   - `pt-serif-400.woff2`
   - `pt-serif-700.woff2`
   - `golos-text-400.woff2`
   - `golos-text-600.woff2`

Если шрифты не добавлены, тема будет использовать системные шрифты (Arial, Times New Roman), но это временное решение.

## Типографика

- **Заголовки**: PT Serif, засечная
- **Основной текст**: Golos Text, гротеск
- **Базовый размер**: 18px минимум
- **Межстрочный интервал**: 1.6
- **Масштабирование**: через `clamp()` от 320px до 1920px

## Главные особенности

✓ **Спокойный интерфейс** — подходит для людей в сложное время  
✓ **Пошаговый блок** "Что делать сейчас" на главной странице  
✓ **Локальные шрифты** — без CDN, всё работает локально  
✓ **Темная тема** — автоматически по `prefers-color-scheme`  
✓ **Доступность** — видимый фокус клавиатуры, контраст AA+  
✓ **Без jQuery** — используется только нативный JavaScript  
✓ **Адаптив** — от 320px до 1920px  
✓ **Block Theme** — полностью на `theme.json`  

## Проверка качества

Перед запуском проверьте:

1. **PHP ошибки** — откройте WordPress, проверьте `debug.log`
2. **Визуальный вид** — откройте на разных экранах (320px, 768px, 1440px, 1920px)
3. **Цвета** — все из палитры, нет посторонних hex
4. **Темная тема** — проверьте в DevTools (Cmd+Shift+P → Dark)
5. **Шрифты** — в DevTools Network убедитесь что это `.woff2` локально
6. **Доступность** — пройдитесь по сайту с помощью Tab
7. **Lighthouse** — Performance ≥90, Accessibility ≥95

## Плагины и интеграция

Тема работает с плагином **razil-core** (уже установлен), который регистрирует:

- **Типы записей**: `services` (услуги), `products` (товары)
- **Таксономии**: `product_category` (разделы каталога)

Тема не дублирует эту функциональность, только выводит в шаблонах.

Плагин также может предоставлять кастомные блоки:
- `razil/faq` — часто задаваемые вопросы
- `razil/price-table` — таблица цен
- `razil/cta` — кнопка призыва к действию

Для них в шаблонах оставлены места, см. `templates/single-services.html`.

## Редактирование в блочном редакторе

Из админ-панели вы можете редактировать:

1. **Главная страница** (front-page.html)
2. **Страницы** (page.html)
3. **Отдельные посты** (single.html)
4. **Заголовки и текст** в шаблонах

Все остальное (цвета, шрифты, макет) меняется через:
- **theme.json** — структурные изменения, палитра, типографика
- **assets/css/main.css** — дополнительные стили
