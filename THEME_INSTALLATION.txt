          УСТАНОВКА И АКТИВАЦИЯ ТЕМЫ RAZIL
═════════════════════════════════════════════════════════════════

✅ ЧТО СДЕЛАНО
─────────────────────────────────────────────────────────────────
Создана новая Block Theme «Razil» для WordPress с полной
функциональностью и правильной структурой для ритуального
агентства.

Расположение: wp-content/themes/razil/

СОДЕРЖИТ:
• theme.json         - палитра, типография, макет
• functions.php      - подключение стилей и функции
• 11 HTML шаблонов   - для всех типов страниц
• CSS стили          - главная тема и редактор
• Структуру папок    - для шрифтов, CSS, JS


⚙️  АКТИВАЦИЯ ТЕМЫ (ШАГ 1)
─────────────────────────────────────────────────────────────────
1. Откройте WordPress админ-панель
   http://ra-zil.test/wp-admin

2. Перейдите: Внешний вид → Темы

3. Найдите карточку темы "Razil"

4. Нажмите кнопку "Активировать"

После активации тема заменит текущую тему.


📥 ЗАГРУЗКА ШРИФТОВ (ШАГ 2 - ВАЖНО!)
─────────────────────────────────────────────────────────────────
Тема будет работать с системными шрифтами, но для правильного
вида нужны локальные шрифты PT Serif и Golos Text в формате
.woff2.

СПОСОБ А: Автоматическая загрузка (через PowerShell)
─────────────────────────────────────────────────────────────────
1. Откройте PowerShell или Command Prompt

2. Перейдите в папку темы:
   cd wp-content\themes\razil

3. Запустите скрипт:
   .\download-fonts.ps1

Скрипт скачает все необходимые шрифты автоматически.

СПОСОБ Б: Ручная загрузка (через Google Fonts)
─────────────────────────────────────────────────────────────────
1. Откройте https://fonts.google.com

2. Найдите "PT Serif"
   - Скачайте начертания: Regular (400) и Bold (700)
   - Убедитесь что это файлы .woff2
   - Сохраните в: wp-content/themes/razil/assets/fonts/

   Файлы должны быть:
   - pt-serif-400.woff2
   - pt-serif-700.woff2

3. Найдите "Golos Text"
   - Скачайте начертания: Regular (400) и Semibold (600)
   - Убедитесь что это файлы .woff2
   - Сохраните в: wp-content/themes/razil/assets/fonts/

   Файлы должны быть:
   - golos-text-400.woff2
   - golos-text-600.woff2

Итого должно быть 4 файла .woff2 в папке fonts/.


🔍 ПРОВЕРКА
─────────────────────────────────────────────────────────────────
После активации темы проверьте:

1. Главная страница
   http://ra-zil.test
   ✓ Должна отобразиться главная страница с блоком
     "Что делать сейчас" (пошаговая инструкция)
   ✓ Все цвета должны быть из палитры
   ✓ Текст должен быть читаемым (18px минимум)

2. Архив услуг
   http://ra-zil.test/uslugi/
   ✓ Должны отобразиться карточки услуг
   ✓ Если нет данных - это нормально, нужно добавить записи

3. Раздел каталога
   http://ra-zil.test/katalog/
   ✓ Должна отобразиться главная страница каталога

4. Страница ошибки
   http://ra-zil.test/ne-sushestvuet/
   ✓ Должна отобразиться 404 страница с навигацией

5. Темная тема (если нужна проверка)
   - Откройте DevTools (F12)
   - Нажмите Cmd/Ctrl+Shift+P
   - Введите "Dark" или откройте Settings → Preferences
   - Выберите Dark mode
   ✓ Все цвета должны инвертироваться автоматически


✏️  РЕДАКТИРОВАНИЕ СОДЕРЖИМОГО
─────────────────────────────────────────────────────────────────
В админ-панели можно редактировать:

1. Главную страницу
   Внешний вид → Редактор → Главная страница

2. Обычные страницы и посты
   Страницы / Посты → редактируйте как обычно

3. Заголовок и описание сайта
   Параметры → Основные

4. Меню
   Внешний вид → Меню

Палитра, шрифты, макет меняются в:
• theme.json (структурные изменения)
• assets/css/main.css (дополнительные стили)

❓ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
─────────────────────────────────────────────────────────────────
1. Проверьте PHP ошибки
   wp-content/debug.log

2. Очистите кеш браузера
   Ctrl+Shift+Delete или Cmd+Shift+Delete

3. Проверьте версию WordPress
   Должна быть 6.4+

4. Проверьте наличие шрифтов
   Откройте DevTools → Network → отфильтруйте по "font"
   Должны быть локальные .woff2 файлы
