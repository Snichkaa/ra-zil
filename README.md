# Сайт агентства «Земля и Люди»

Собственная тема и плагин WordPress для сайта [ra-zil.ru](https://ra-zil.ru/).
Рабочая ветка новой версии — `redesign/concept-v2`.

## Состав репозитория

- `wp-content/themes/razil/` — шаблоны, стили, JavaScript, шрифты, иконки и исходники блоков.
- `wp-content/themes/razil/build/` — готовые файлы блоков, которые WordPress использует при работе сайта. Они включены в Git: сборка на хостинге не требуется.
- `wp-content/plugins/razil-core/` — услуги, формы связи, настройки организации, микроразметка и другая логика сайта.
- `package.json` и `package-lock.json` внутри темы — зависимости и команды для разработки блоков.

Отчёты, скриншоты, документы аудита, разовые скрипты, резервные копии, временные файлы и `node_modules` исключены из Git. Локальные экземпляры сохранены. История прежних коммитов не переписывается.

## Установка и перенос

1. Подготовить WordPress и PHP, совместимые с темой и плагинами. `razil-core` объявляет минимум WordPress 6.5 и PHP 8.1; требования остальных компонентов нужно проверить отдельно.
2. Скопировать каталоги темы `razil` и плагина `razil-core` в соответствующие папки `wp-content`.
3. Восстановить базу данных, `wp-content/uploads/`, конфигурацию сервера и необходимые сторонние плагины из отдельной резервной копии. В текущем проекте SEO-метаданные используются через Yoast SEO (`wordpress-seo`).
4. Настроить `wp-config.php` на сервере, активировать тему и плагин, проверить постоянные ссылки, формы, изображения и виртуальный тур. При смене домена заменить адреса в базе инструментом, учитывающим сериализованные данные WordPress.

**Репозиторий сохраняет код, но не является полной резервной копией сайта.** Тексты страниц, услуги, настройки, SEO-метаданные и заявки находятся в базе WordPress. Фотографии, видео и виртуальный тур — в `wp-content/uploads/`. Ядро WordPress и сторонние плагины устанавливаются отдельно. База, медиа, пароли, ключи и `wp-config.php` в GitHub не публикуются.

Отправка коммита в GitHub сама по себе не переносит сайт на основной домен.

Общие стили редактируются в `assets/css/main.css`, `information.css` и `service-details.css` темы. После изменения выполните `npm run build:styles` из каталога темы и сохраните соответствующие `.min.css`: именно они подключаются на сайте. Исходники и команда сборки остаются в репозитории.
