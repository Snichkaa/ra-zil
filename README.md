# Сайт агентства «Земля и Люди»

Репозиторий содержит собственную тему WordPress `razil`, плагин `razil-core`, инструменты разработки и документацию сайта.

## Что хранится в Git

- `wp-content/themes/razil/` — шаблоны, стили, скрипты, шрифты и исходники блоков. Каталог `build/` включён: WordPress использует готовые файлы блоков, сборки на сервере нет.
- `wp-content/plugins/razil-core/` — типы записей, формы связи, данные организации, микроразметка и другая логика сайта.
- `_docs/` и текстовые отчёты `_reports/` — концепция, решения и результаты проверок.
- Общие инструменты `_tools/redesign/`, включая SEO-карту `seo-map-2026-10.json`, её генератор и скрипт применения метаданных.

## Что сохраняется отдельно

В репозиторий не входят ядро WordPress, сторонние плагины и темы, переводы, `node_modules`, `wp-config.php`, дампы базы и каталог `wp-content/uploads/`.

**Клон репозитория не является полной резервной копией сайта.** Тексты страниц, записи услуг, SEO-метаданные, настройки и заявки находятся в базе WordPress. Фотографии, видео и виртуальный 3D-тур находятся в `uploads`. Для восстановления или переноса нужны база данных, медиа и соответствующая конфигурация сайта.

Локально также остаются резервные копии `_backup/`, пакеты переноса `_deploy/`, результаты проверок `_check/`, старые скриншоты `_reports/shots/`, исходники импорта `_import/` и рабочие Excel-таблицы `_reports/*.xlsx`. Они исключены через `.gitignore`.

Скрипты этапов `_tools/t1/` … `_tools/t5/` и промежуточные заготовки завершённых переработок также сохранены локально. Перед повторным применением скриптов, меняющих базу, необходимо проверить исходные данные и сделать резервную копию.

## Как отправить текущие изменения

На 14 октября 2026 текущая рабочая ветка — `redesign/concept-v2`, удалённый репозиторий `origin` — `https://github.com/Snichkaa/ra-zil.git`.

В терминале PowerShell из проекта:

```powershell
Set-Location 'C:\laragon\www\ra-zil'
git status --short
git add -A
git diff --cached --stat
git commit -m "Обновить страницы, SEO и формы связи; очистить репозиторий"
git push -u origin redesign/concept-v2
```

Команды выполняются по порядку. Если команда завершается ошибкой, сначала нужно разобраться с ней, затем переходить к следующей.

После очистки в `git status` много строк `D`: это подготовленное удаление служебных файлов из репозитория. За исключением удалённых устаревших журналов, сами файлы сохранены на диске и теперь игнорируются. `git add -A` добавит изменения `.gitignore`, рабочие исходники и документацию к уже подготовленным удалениям.

`push` отправляет эту ветку в GitHub. Он не публикует сайт на хостинге и не переносит базу данных или медиа. Для включения изменений в `main` после загрузки можно создать Pull Request из `redesign/concept-v2`.
