# Задача: block theme для сайта ритуального агентства

## Контекст проекта

Разрабатывается новый сайт для ООО «Земля и Люди» — ритуальное агентство в Хабаровске,
работает с 2014 года, четыре филиала (Хабаровск, Амурск, Биробиджан и ещё один
уточняется). Сайт переезжает с 1С-Битрикс на WordPress. Домен ra-zil.ru.

Аудитория: люди в остром горе, часто в первые часы после утраты. Много людей 45+.
Заходят с телефона, в спешке, часто ночью. Задача сайта — быстро дать понять,
что делать прямо сейчас, и вызвать доверие к организации.

Это определяет всё остальное: интерфейс должен быть спокойным, предельно понятным
и не требовать усилий. Никакой продающей агрессии.

## Окружение

- WordPress 7.0.2, PHP 8.3, MySQL, Apache (Laragon)
- Корень сайта: `C:\laragon\www\ra-zil`
- Локальный адрес: `http://ra-zil.test`
- Уже установлен и активирован плагин `razil-core` в `wp-content/plugins/razil-core`

## Что уже сделано плагином razil-core — НЕ дублировать в теме

Плагин регистрирует типы записей и структуру адресов. Тема отвечает только
за представление. Не регистрируй типы записей, таксономии и rewrite-правила в теме.

Зарегистрировано:

| Сущность | Тип | Адрес |
|---|---|---|
| Услуги | CPT `services` | `/uslugi/{slug}/`, архив `/uslugi/` |
| Товары | CPT `products` | `/katalog/{раздел}/{slug}/` |
| Разделы каталога | таксономия `product_category` | `/katalog/{slug}/` |

Слаги услуг: `organizaciya-pohoron`, `kremaciya`, `transportirovka`,
`blagoustroystvo`, `yuridicheskaya-pomoshch`, `prizhiznennyy-dogovor`.

Разделы каталога: `groby`, `venki`, `pamyatniki`, `ogradki`, `keramika`,
`stoly-i-lavki`, `kresty`, `prinadlezhnosti`.

## Что нужно сделать

Собственную block theme с именем `razil` в `wp-content/themes/razil`.

### Обязательные требования

- Block theme на `theme.json`, без классических `header.php`/`footer.php`
- Никаких сторонних тем-родителей, никаких page builder'ов
- Никаких CDN: шрифты только локально, в `assets/fonts/`
- Без jQuery на фронтенде. JavaScript — только нативный, и только там, где без него нельзя
- Русский язык интерфейса и контента, реальные тексты, не «Lorem ipsum»
- Адаптив от 320 до 1920 px
- Видимый фокус клавиатуры, `prefers-reduced-motion` уважается
- Контраст текста не ниже AA

## Цветовая палитра — задана заказчиком, использовать точно

Светлая тема:

| Роль | HEX | Slug для theme.json |
|---|---|---|
| Тёмно-зелёный (акцент, кнопки) | `#234A38` | `accent` |
| Бежевый (фон страницы) | `#F4EFE5` | `base` |
| Бежевый светлый (карточки) | `#FCFAF5` | `surface` |
| Графит (основной текст) | `#2E2E2C` | `text` |
| Графит светлый (вторичный текст) | `#6B6660` | `text-muted` |
| Коричневый (цены, детали) | `#7A5A3E` | `detail` |
| Граница | `#DED5C4` | `border` |

Тёмная тема (парные значения, реализовать через `prefers-color-scheme` в CSS-переменных):

| Роль | HEX |
|---|---|
| Акцент | `#8CBFA5` |
| Фон | `#1B1B19` |
| Карточки | `#252422` |
| Текст | `#EDE6D9` |
| Вторичный текст | `#A29B90` |
| Детали | `#C79E77` |
| Граница | `#3B3934` |

Палитру не расширять и не «улучшать». Если понадобится дополнительный оттенок —
брать прозрачность от существующего цвета, а не новый hex.

Тёмно-зелёный — акцентный, а не декоративный: он маркирует действия
(кнопки, ссылки, активные состояния). Коричневый — только для цен, дат,
единиц измерения и подобных фактических деталей. Не смешивать роли.

## Типографика

Нужны две гарнитуры с полной поддержкой кириллицы, обе с открытой лицензией
и подключением локальными файлами.

**Заголовки** — засечная, с русской книжной родословной, спокойная и не «журнальная».
Кандидаты: Alice, PT Serif, Lora. Проверь наличие нужных начертаний и кириллицы,
выбери одну и обоснуй выбор в комментарии к `theme.json`.

**Основной текст** — гротеск с высокой разборчивостью, рассчитанный на чтение
с телефона людьми старшего возраста. Кандидаты: Golos Text, Onest, Inter.

Ограничения:

- Не более двух гарнитур и не более трёх начертаний суммарно (например, 400 и 600
  для текста, 400 для заголовков). Каждое лишнее начертание — это запрос и вес
- Формат `.woff2`, подмножество только с кириллицей и латиницей
- `font-display: swap`
- Базовый размер текста не меньше 18px, межстрочный не меньше 1.6 —
  это требование аудитории, а не вкусовщина
- Шкала размеров через `clamp()`, задать в `theme.json` как `fontSizes`

## Направление и «подпись» дизайна

Главную страницу построй не вокруг рекламного слогана, а вокруг **последовательности
действий**. Человек, который открыл сайт в четыре утра, должен сразу увидеть, что
делать в первые часы и в первые дни. Нумерация уместна именно здесь, потому что
это настоящая последовательность, а не украшение.

Это и есть «подпись» темы — спокойный пошаговый блок «Что делать сейчас».
Смелость расходуем только на него, всё остальное держим тихим и дисциплинированным.

Чего избегать категорически:

- Стоковых фотографий плачущих людей, свечей, силуэтов на закате
- Слов «дешево», «выгодно», «скидка», «акция», восклицательных знаков
- Всплывающих окон, таймеров, «осталось 3 места»
- Анимации ради анимации. Допустимы только короткие переходы состояний до 200ms
- Круглых аватарок с отзывами и прочих приёмов из лендингов инфобизнеса

Тон текстов: короткие фразы, глаголы в действительном залоге, никакого канцелярита.
«Позвоните, мы приедем в течение часа» — а не «Осуществляется оперативный выезд
специалиста».

## Что должно быть в шаблонах

**`parts/header.html`** — логотип-текст, основное меню, телефон крупно и заметно
(круглосуточно), кнопка вызова. На мобильном телефон должен быть доступен
без раскрытия меню.

**`parts/footer.html`** — контакты всех филиалов, ссылки на политику и согласие
на обработку персональных данных, реквизиты, график работы.

**`templates/front-page.html`** — блок «Что делать сейчас» как главный элемент,
далее услуги, каталог, доверие (лицензии, опыт с 2014 года), контакты.

**`templates/single-services.html`** — заголовок, что входит в услугу,
какие документы нужны от клиента, сроки, ориентировочная стоимость,
блок вопрос-ответ, кнопка обращения. Оставь места под будущие блоки плагина
(`razil/faq`, `razil/price-table`, `razil/cta`) — они появятся позже.

**`templates/single-products.html`** — изображение, название, цена (коричневым),
характеристики, кнопка «Уточнить наличие». Корзины нет.

**`templates/taxonomy-product_category.html`** — сетка товаров раздела,
изображение, название, цена.

**`templates/404.html`** — обязательно с настоящим кодом 404 и с понятной
навигацией: телефон, ссылки на основные разделы.

## Приёмка

Проверю по этим пунктам:

1. Тема активируется без ошибок PHP, `debug.log` пустой
2. Открываются и корректно выглядят: `/`, `/uslugi/`, `/uslugi/kremaciya/`,
   `/katalog/venki/`, `/katalog/venki/venok-11/`, `/404-test/`
3. Вёрстка не ломается на 320, 375, 768, 1440, 1920 px
4. Все цвета — из заданной палитры, посторонних hex в CSS нет
5. Тёмная тема работает по `prefers-color-scheme`
6. Шрифты грузятся локально, запросов к внешним доменам нет
7. Навигация проходится с клавиатуры, фокус виден на каждом элементе
8. Lighthouse: Performance не ниже 90, Accessibility не ниже 95
9. jQuery на фронтенде не подключается

## Порядок работы

Сначала покажи мне план: выбранные гарнитуры с обоснованием, шкалу размеров,
шкалу отступов, структуру главной страницы схемой. Дождись подтверждения.
Только потом пиши код.

При написании кода следи за специфичностью CSS-селекторов: в block theme легко
получить конфликт между стилями из `theme.json` и `main.css`. Отступы между
секциями задавай в одном месте, а не в двух конкурирующих правилах.

Комментарии в коде — на русском, объясняющие «почему», а не «что».
