## 12. Команды отката

Полный откат на состояние до запуска:

```
git checkout main
git branch -D redesign/concept-v2
```

Откат только файлов темы и плагина, без смены ветки:

```
git checkout 33fd586 -- wp-content/themes/razil wp-content/plugins/razil-core
```

Откат содержимого записей из дампа БД (все записи разом):

```
mysql -u root -p ra_zil < _backup/redesign-2026-09-19/wp_posts_postmeta.sql
```

Откат одной записи — команды добавляются по мере обработки страниц в фазах 5 и 6.
