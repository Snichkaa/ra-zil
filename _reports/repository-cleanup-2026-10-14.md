# Подготовка репозитория к загрузке

Дата: 14 октября 2026. Ветка: `redesign/concept-v2`.

Состав репозитория очищен от локальных материалов. Коммит и отправка в GitHub оставлены пользователю.

## Выполнено

- Обновлён `.gitignore`: добавлены локальные настройки редактора, результаты аудита, скриншоты, снимки текста, Excel-таблицы, служебные скрипты прошлых этапов, промежуточные заготовки и кэши Python.
- Из индекса Git убраны 438 ранее отслеживаемых файлов. Одного `.gitignore` для них было недостаточно. Сохраняемые 436 файлов остались на диске; их контрольные суммы после операции совпали.
- Исключены из отслеживания 208 скриншотов, 88 файлов перевода WordPress, 39 файлов старого импорта, 94 файла этапов `t1`–`t3`, пять снимков текста, один старый снимок главной страницы и три вспомогательных файла завершённого редизайна.
- Физически удалены четыре устаревших журнала импорта: `crawl.out`, `scrape.out`, `crawl.log`, `scrape.log`. Два файла `.out` входили в 438 ранее отслеживаемых файлов; журналы `.log` уже игнорировались.
- Удалены десять автоматически создаваемых файлов кэша Babel из `node_modules/.cache/babel-loader/`. Сами зависимости и готовая сборка блоков сохранены.
- Добавлен [README](../README.md) с составом репозитория и командами отправки изменений.

Объём сохраняемых локально файлов, исключённых из индекса, составляет около 182,5 МиБ. История прежних коммитов не переписывалась: удаление из текущего состава не удаляет старые версии из истории Git.

## Что сохранено в репозитории

Исходники темы и плагина, готовые блоки `build/`, шрифты, иконки, `package.json`, `package-lock.json`, концепция дизайна, текстовые отчёты, общие инструменты проверки и SEO-карта в JSON.

В локальном проекте сохранены WordPress, переводы, сторонние плагины, фотографии, виртуальный тур, резервные копии, Excel-таблицы и исторические материалы разработки. Код сайта и содержимое базы данных при этой очистке не изменялись.

## Проверка

- После очистки среди отслеживаемых файлов нет файлов, подпадающих под `.gitignore`.
- В состав будущего коммита не входят `wp-config.php`, SQL-дампы, `uploads`, зависимости, резервные копии и результаты локальных проверок.
- Контрольные суммы всех 436 сохраняемых файлов, исключённых из индекса, совпали с исходными.
- Изменения `.gitignore` и служебные удаления проверены отдельно от существующих правок сайта.
- Пробный `git add --dry-run -A` прошёл; рабочие исходники не добавлялись в индекс автоматически. В индексе подготовлены только 438 удалений служебных файлов.
- После очистки главная, «Кремация», «Контакты», «Отзывы» и фотография первого экрана отвечают HTTP 200. Наличие сборки блоков, файлов перевода, 3D-тура и актуальной Excel-таблицы подтверждено.

Резервная копия прежнего `.gitignore`, индекса, удалённых журналов и перечень исключённых файлов находятся в `_backup/repository-cleanup-2026-10-14/`. Этот каталог игнорируется.

Сохранение кода в Git не заменяет резервную копию WordPress: текущие страницы и SEO-настройки хранятся в базе, медиа и 3D-тур — в `wp-content/uploads/`.
