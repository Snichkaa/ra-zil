# Оформление страниц услуг

Дата: 13 октября 2026 года.

Все пять страниц услуг приведены к оформлению, одобренному на странице «Кремация»: компактные отступы, согласованные сетки, навигация по разделам, спокойные заглушки фотографий и адаптивная таблица цен.

## Изменения

- Общие стили вынесены в `wp-content/themes/razil/assets/css/service-details.css`. Подключаются только на отдельных страницах услуг через `functions.php` и класс `rz-svc-layout`.
- Оформление «Кремации» стало общей основой. Её отдельный CSS заменён общим файлом, специальные классы переименованы в `rz-svc-*`.
- Во вступлениях текст распределён по двум колонкам. Длинные абзацы разделены по границам предложений с сохранением формулировок. У организации похорон сохранена карточка первых действий.
- На перевозке сохранены оба раздела: виды перевозок и состав услуги. Каждый получил собственный пункт навигации.
- Длинные перечни документов используют всю ширину раздела и две колонки внутри карточки. Исключения расположены ниже. На узком экране и при увеличении текста списки перестраиваются в одну колонку.
- У организации похорон сохранены четыре комплекса. На остальных страницах таблица стоит рядом с пояснением и кнопкой уточнения стоимости. На странице документов в этот раздел перенесён существующий абзац о бесплатной первичной консультации.
- Итоговое выделение в таблице применяется к строке с выделенным итогом, а не к любой последней услуге.
- На всех страницах оставлены только заглушки фотографий. Всего 23 места, номера начинаются с 1 на каждой странице и совпадают со [списком кадров](photos-services-2026-10-13.md). Фото 1 — первый экран.
- Все 33 значения в прайсах и ценах комплексов остались `…` или `от …`. Составы незаполненных комплексов также не дополнялись.
- Названия, адреса, отрывки, статусы записей, привязки изображений в медиатеке и SEO-метаданные сохранены. Существующие тексты услуг и ответов на вопросы сохранены; изменены структура, заголовки вступлений и подписи заглушек.

## Проверки

- Пять страниц на ширинах 320, 375, 768, 1024, 1366 и 1920 px: нет горизонтального переполнения, один H1, последовательная нумерация фотографий, нет ошибок JavaScript.
- На каждой странице проверены мобильный вид, тёмная тема и увеличение размера текста до 200% при ширине 768 px.
- Навигация ведёт к существующим разделам, заголовки не перекрываются фиксированной шапкой.
- Кнопки обращения открывают одно общее окно; Escape закрывает его и возвращает фокус. Заявки не отправлялись.
- FAQ проверен с клавиатуры; одновременно открыт один ответ.
- Axe не обнаружил нарушений проверяемых правил WCAG A/AA в содержимом страниц. Проверка ограничена `.entry-content`.
- В редакторе WordPress проверен 601 блок: невалидных блоков нет.
- Записанное содержимое каждой страницы побайтово совпало с подготовленным HTML. PHP-синтаксис и `git diff --check` прошли.

## Файлы и воспроизведение

- `wp-content/themes/razil/functions.php` — подключение общих стилей и класс страницы.
- `wp-content/themes/razil/assets/css/service-details.css` — оформление всех страниц услуг.
- `wp-content/themes/razil/assets/icons/service-photo.svg` — значок заглушки.
- `_tools/redesign/services-2026-10.php` — подготовка кандидатов из резервной копии и списка кадров, без публикации.
- `_tools/redesign/prepare-services.mjs` — нормализация через реальный реестр блоков WordPress.
- `_tools/redesign/services-content/11.html` … `15.html` — итоговое содержимое записей. Эти файлы нужны при переносе изменений вместе с темой: содержимое страниц хранится в базе WordPress.
- `_tools/redesign/write-post.php <ID> <HTML>` — существующий скрипт записи с проверкой до и после сохранения. При переносе на другую базу сначала сопоставить ID с адресами из таблицы выше.
- `_tools/redesign/check-services.mjs` — проверки `before`, `layout`, `ui` и `preview`; необязательный третий аргумент — ID через запятую.
- `_check/services-2026-10-13/` — локальные результаты проверок и снимки, не включаются в Git.

## Резервная копия

`_backup/services-2026-10-13/` содержит исходный HTML и метаданные пяти записей, прежний `functions.php`, CSS «Кремации» и её значок заглушки. На момент копирования «Кремация» уже имела одобренное оформление, остальные четыре страницы — сентябрьское.

Для возврата содержимого используется `restore-post.php <ID> _backup/services-2026-10-13`. Для полного возврата оформления дополнительно восстановить `functions.php`, `assets/css/cremation.css` и `assets/icons/cremation-photo.svg` из этой папки.

Следующий шаг по наполнению — подобрать собственные фотографии по [списку кадров](photos-services-2026-10-13.md), затем отдельно заполнить цены и составы комплексов.
